# Tasks — Future Roadmap

This document outlines upcoming minimalist enhancements and structural refinements.

## 🚀 Minimalist Enhancements

- [ ] **Inline Text Editing**
  - Allow double-clicking a task title to edit it inline, retaining the document-editor experience.
- [ ] **Inline Markdown Parsing**
  - Parse standard markdown styling (like `**bold**`, `*italic*`, or `` `code` ``) inside the task text.
- [ ] **Drag & Drop Row Reordering**
  - Implement a flat drag handle to easily change task priorities or manual order.
- [ ] **Multi-Notebook Support**
  - Organize lists into separate flat notebooks or pages (e.g. Daily, Projects, Archive).
- [ ] **Custom Pastel Color Schemes**
  - Let users customize desaturated pastel themes directly from a simple setting bar.
