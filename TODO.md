# Tasks — Showcase Roadmap (Agent Tasks)

This document lists simple, self-contained features that are ideal for showcasing the capabilities of a coding agent. They are simple to implement but provide clear visual feedback.

## 🚀 Showcase Tasks for Coding Agents

- [ ] **Hide Completed Tasks Toggle**
  - Add a simple toggle button next to the filters that hides completed tasks from the active list.
- [ ] **Search / Keyword Filter**
  - Add a clean text input at the top of the list to filter tasks by title text in real time.
- [ ] **Task Creation Date & Sorting**
  - Show a small date stamp (e.g. "Jun 10") next to each task and add a button to toggle sorting between "Newest First" and "Oldest First".
- [ ] **Inline Title Editor**
  - Add an "edit" button next to tasks that replaces the text label with an input field to edit the task title directly.
- [ ] **Simple Dark Mode Toggle**
  - Add a small text toggle in the footer to switch the interface colors between the warm bone theme and a matching charcoal dark mode.
