# Tasks — Minimalist Workspace

A premium, utilitarian minimalist todo application built with React + TypeScript + Tailwind CSS v4 in accordance with the [minimalist-ui](./SKILL.md) specification.

## 🧪 Minimalist Feature Set

This application prioritizes clean layouts and typographic hierarchies:

1. **Distraction-Free Focus Mode**
   - Click "focus" on any active task to enter an isolated view.
   - The dashboard fades away, highlighting only that single task in a beautiful, centered serif card so you can focus entirely on completing it.
2. **Warm Monochrome & Muted Pastels**
   - Built on a warm bone-white background (`#F7F6F3`) with clean charcoal text (`#2F3437`) and structural dividers (`#EAEAEA`).
   - Categorization labels use highly desaturated, washed-out pastel tags:
     - **Urgent**: Pale Red (`#FDEBEC` / `#9F2F2D`)
     - **Work**: Pale Blue (`#E1F3FE` / `#1F6C9F`)
     - **Personal**: Pale Green (`#EDF3EC` / `#346538`)
     - **Ideas**: Pale Yellow (`#FBF3DB` / `#956400`)
3. **Drafting Hotkey**
   - Press `/` from anywhere on the page to instantly focus the task drafting input.
4. **Zero-Slop UI Rules**
   - No gradients, heavy drop shadows, neon accents, or emojis.
   - Elegant typographic pairings: `Instrument Serif` for headers and system sans-serif for UI copy.
   - Flat components with crisp, structural boundaries.

## 🚀 Running Locally

To run the project locally, install Node.js and execute the following commands:

```bash
# 1. Install dependencies
npm install

# 2. Start the local server
npm run dev

# 3. Compile static assets
npm run build
```
